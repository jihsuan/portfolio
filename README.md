# Hsuan — Shopify 設計與改版作品集

- index.html：作品集首頁，含後台到商品頁的互動重製展示。

## 公開展示

本網站為個人作品與專案歷史展示，並非 MOVA 官方營運商店。售價、活動與供貨狀態為保存當日紀錄；展示購物車不會建立訂單或付款。本專案未包含 Shopify 後台、會員與訂單資料。YouTube 原影片播放仍需連線。
